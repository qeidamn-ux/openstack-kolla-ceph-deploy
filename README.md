# OpenStack — Automation Suite (Consolidated Release)

**Package Date:** 2026-10-15. **DEPLOY** package: contains everything required to deploy the cloud. Functional tests (offline gates, functional checks, KVM lab VM provisioning) are located in the **FUNCTIONAL TESTS** package of the same `v1.7` release. This is optional and, if placed in a sibling directory alongside this one (`OPENSTACK_tests_*`), `run_all.sh` and `install.sh` will locate it automatically (otherwise specify `TESTS_DIR=/path`).
